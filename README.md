# 🎁 元旦神秘礼物抽奖

一个精美的元旦主题在线抽奖网页，适合情侣、朋友之间互动使用。

## ✨ 在线体验

👉 [点击这里开始抽奖](https://你的用户名.github.io/lottery/)

## 🎯 奖项设置

| 奖项 | 奖品 | 概率 |
|------|------|------|
| 🥇 一等奖 | 52元红包 | 5% |
| 🥈 二等奖 | 自选官周报销（30元以内）| 10% |
| 🥉 三等奖 | 小蛋糕一个 | 20% |
| 🏅 四等奖 | 5.2元红包 | 30% |
| 🎖️ 五等奖 | 0.52元红包 | 35% |

## 🌟 功能特点

- 🎨 粉色渐变背景，温馨节日氛围
- 🦌 浮动的礼物、小鹿、烟花等装饰元素
- 🎁 礼物盒弹跳动画
- 🎊 五彩纸屑庆祝效果
- 📱 响应式设计，手机电脑都能用

## 🚀 使用方法

1. Fork 这个仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支
4. 保存后等待几分钟即可通过 `https://你的用户名.github.io/仓库名/` 访问

## 🛠️ 自定义奖项

编辑 `script.js` 文件中的 `prizes` 数组即可自定义奖项：

```javascript
const prizes = [
    {
        level: '一等奖',
        detail: '52元红包 🧧',
        icon: '🎊',
        probability: 0.05  // 5%概率
    },
    // ... 添加更多奖项
];
```
